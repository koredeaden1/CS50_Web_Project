This CS50 project is a web-based application, based in part on the web track's distribution code, that uses Python, SQL, HTML and JavaScript. This application allows users to build their own soccer teams consisting of 11 players with a budget of 500 pounds using different webpages accessible from the links on the navigation bar.
Firstly, users are required to register, if they haven't, and then login to access their personalized session in the application. The webpages in this web application are further explained below.
•	Home: Users can see a table displaying the information on the players bought, the amount of cash remaining for spending, and the total value of the team.
•	Quote: Users can query the application's soccer player's database for player information by submitting a form indicating a specified player position.
•	Buy: Users can buy a soccer player of interest by submitting a form requiring the player's position and the player's name.
•	Sell: Users can sell a player already bought by  using the select menu provided on the webpage.
•	Add: Users can add a maximum of 500 pounds at a time to their cash account.
•	History: Users can see all the purchase and sale transactions they've performed and the date at which they performed it.
•	Images: Users can see a slideshow of certain Champions League moments I consider iconic. All pictures are appropriately referenced.
